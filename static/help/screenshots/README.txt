SCHERMAFBEELDINGEN VOOR HET HELPCENTRUM (Rode Kruis Map Generator)
====================================================================

Plaats de schermafbeeldingen (.png bestanden) in deze map (`static/help/screenshots/`).
Zodra een bestand met de juiste naam hier geplaatst wordt, toont het Helpcentrum direct de afbeelding in plaats van het placeholder-kader.

Lijst van verwachte bestandsnamen per pagina/onderdeel:
--------------------------------------------------------------------
1.  dashboard.png             -> Dashboard & Kaartgeneratie (/ en /#dashboard)
2.  preview_map.png           -> Kaart Preview & Download (/maps/preview/...)
3.  departments.png           -> Afdelingen Overzicht (/departments)
4.  edit_department.png       -> Afdeling Toevoegen / Bewerken (/departments/edit/...)
5.  merge_departments.png     -> Afdelingen Fusie / Samenvoegen (/departments/merge)
6.  provinciale_zetels.png    -> Provinciale Zetels (/provinciale-zetels)
7.  sit_locations.png         -> SIT Locaties (/sit-locations)
8.  112_standplaatsen.png     -> 112 Standplaatsen (/112-standplaatsen)
9.  regions.png               -> Regio's Beheer (/regions)
10. clusters.png              -> Clusters Beheer (/clusters)
11. vrijwilligerskorpsen.png  -> Vrijwilligerskorpsen & Dekking (/vrijwilligerskorpsen)
12. audit_logs.png            -> Logboek / Audit Trail (/audit-logs)
13. users.png                 -> Gebruikersbeheer (/users)
14. change_password.png       -> Wachtwoord Wijzigen (/profile/change-password)
15. login.png                 -> Inloggen (/login)
16. blanco_gegevens.png       -> Sectie 7: Blanco / Ontbrekende Gegevens
